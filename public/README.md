# `packages/public`

Canonical shared static branding assets (`favicon.svg`, `favicon.ico`, `logo.svg`, `logo.png`, `icon.png`, `banner.svg`, `banner-dev.svg`, `sitemap.xml`) for **Crea-Accent Studio**.

Run `pnpm studio initialize` after modifying files in this directory to sync them across `apps/*/public` and `clients/desktop/public`.
